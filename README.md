# 🚀 Cursor Clone Cohort

A modern SaaS landing page inspired by [Cursor.com](http://Cursor.com), built using pure HTML and CSS.

This project recreates a production-style AI product landing page including hero section, feature layouts, testimonials, use cases, changelog, highlights, CTA, and footer.

## 🛠 Tech Stack

- HTML5
- CSS3 (Flexbox + Grid)
- Responsive Design
- Custom CSS Variables
- Dark Theme Layout

## 📱 Responsive Design

Breakpoints implemented:

- Desktop → 3 column layouts
- Tablet → 2 columns
- Mobile → 1 column stacked layout

Uses:

- Flexbox
- CSS Grid
- Media Queries
